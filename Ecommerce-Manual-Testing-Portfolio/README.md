# E-commerce Website — Manual Testing Portfolio

A beginner-friendly manual testing practice project covering essential e-commerce workflows. This repository contains test documentation for login, product search, product details, shopping cart, and checkout.

## Project goals
- Practice test scenario identification and test case design.
- Cover positive, negative, boundary, UI, calculation, and navigation checks.
- Prepare realistic but fictional test data.
- Learn to document defects with clear reproduction steps.
- Track execution results transparently.

## How to use
1. Choose an accessible practice e-commerce website or local demo application.
2. Read `Project-Documentation.md`.
3. Review the Test Scenarios and Test Cases sheets.
4. Replace example product data with values available in your selected application.
5. Execute each test case manually.
6. Record the observed result in **Actual Result**.
7. Update **Status** to Pass, Fail, Blocked, or Not Run.
8. Create a bug report only when you reproduce an issue. Add evidence such as screenshots where appropriate.
9. Update the Execution Report after testing.

## Important accuracy note
The test cases are designed but have **not been executed** as part of preparing this portfolio. The execution report starts with all 40 cases marked `Not Run`. The bug report rows are illustrative examples marked `Not Verified`; they are not claims that these defects exist in a real website. Verify every issue before reporting it.
