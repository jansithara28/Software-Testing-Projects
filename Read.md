# Login and Registration Functional Testing

## Project Overview

This project demonstrates manual functional testing of the Login and Registration modules of a web application.

The objective is to validate user authentication, account registration, input validation, error handling and logout functionality through manually designed and executed test cases.

## Application Under Test

**Website:** https://automationexercise.com/

**Testing Type:** Manual Functional Testing
**Testing Approach:** Black-box Testing
**Tools Used:** Microsoft Excel, Web Browser, Git and GitHub

## Project Objectives

* Understand the software testing process.
* Design functional test scenarios.
* Prepare positive and negative test cases.
* Validate login and registration functionality.
* Identify and document defects.
* Execute test cases and record results.
* Prepare a test execution report.

## Testing Modules

### 1. Login Module

* Valid login credentials
* Invalid email and password
* Empty field validation
* Unregistered email validation
* Logout functionality

### 2. Registration Module

* New user registration
* Existing email validation
* Mandatory field validation
* Email format validation
* Personal information validation
* Account creation confirmation

## Testing Methodology

1. Analyze the application functionality.
2. Identify test scenarios.
3. Design positive and negative test cases.
4. Prepare test data.
5. Execute test cases manually.
6. Compare actual and expected results.
7. Document identified defects.
8. Prepare the execution summary.

## Test Execution Status

Test cases are initially marked as **Not Run**.

Execution results will be updated after testing the application.

No defects are claimed unless they are observed and documented during actual execution.
